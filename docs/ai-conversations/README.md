# AI 對話保存說明

本目錄用於保存「爪印留聲」從第一輪開始的完整、原始 AI 開發對話，作為黑客松過程紀錄。

## 重要限制

目前 AI 助手無法從 Kiro 自動匯出本會話的完整原始對話，因此不會在此建立摘要並冒充逐字紀錄，也不會編造缺少的訊息、時間或工具輸出。

請使用者在每個開發階段結束時，從 Kiro 手動匯出完整會話；若目前版本沒有匯出功能，請完整選取並複製對話內容，另存到本目錄。內容應包含：

- 使用者的原始需求與後續訊息。
- AI 的完整回覆。
- 可見的工具操作與實際輸出。
- 必要的日期與階段名稱。

建議檔名：

```text
YYYY-MM-DD-stage-N-full-conversation.md
```

例如：

```text
2026-09-19-stage-1-full-conversation.md
```

## 保存原則

1. 保留原文，不改寫、不節錄、不用摘要取代。
2. 匯出前檢查並移除 API 密鑰、access token、密碼、私人網址與其他敏感資料。
3. 若只能保存部分內容，必須在檔案開頭標示缺少的範圍，不可稱為「完整對話」。
4. 不提交不必要的大型附件；圖片或媒體應另記來源與保存位置。
